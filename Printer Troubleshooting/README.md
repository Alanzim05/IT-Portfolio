# Printer Troubleshooting

## Project Overview
Resolved a simulated printer paper jam incident using the printer's front panel interface and verified the repair with a successful test copy.

**Ticket ID:** INC8554691  
**Device:** Canyon Printer C4750 Series  
**Location:** 2nd Floor Marketing  
**Priority:** P4 Low  
**Environment:** SysDesks Simulated Help Desk Lab

## Problem Description
The requester reported a red paper jam indicator and an error message on the printer. The requester did not want to open the printer themselves.

## Troubleshooting Steps
1. Reviewed the incident details.
2. Opened the printer's front panel interface.
3. Read the paper jam instructions.
4. Followed the instructions for the rear access door and Tray 2 feed path.
5. Confirmed the paper jam error cleared.
6. Performed a test copy to verify the printer was working.

## Resolution
The paper jam error cleared after following the front panel instructions. A test copy completed successfully, confirming that the printer was operational.

## Skills Demonstrated
- Hardware troubleshooting
- Printer front panel navigation
- Paper jam diagnosis and resolution
